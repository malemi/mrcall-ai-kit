---
description: Manage the opt-in scope guard for OpenCode
---

For `on`, `off`, `status`, or `unregister`, run
`python3 ~/.config/mrcall-ai-kit/scope-guard/scope_guard_register.py opencode $ARGUMENTS`
and report its output. For unmark, run
`python3 ~/.config/mrcall-ai-kit/scope-guard/scope_guard.py unmark <nonce>` as the
agent's own deliberate follow-up action. Never ask the operator to approve it or
an ordinary guarded edit.
